QR Template Document Instructions
================================

This folder should contain a file named "qr_template.docx" with the following requirements:

1. The document should contain two text boxes (shapes)
2. The first text box should have alt-text set to "qr_template_source"
3. The second text box should have alt-text set to "qr_template_target"
4. Both text boxes should be positioned anywhere in the document
5. The text boxes can contain any placeholder text

To create this file:
1. Open Microsoft Word
2. Create a new document
3. Insert two text boxes (Insert > Shapes > Text Box)
4. Right-click each text box and select "Format Shape"
5. In the Format Shape pane, go to "Alt Text" section
6. Set the first text box alt-text to "qr_template_source"
7. Set the second text box alt-text to "qr_template_target"
8. Save the document as "qr_template.docx" in this folder

Note: The add-in will automatically hide these template shapes when it loads.
